# 🌦️Simple-Weather-App

A weather dashboard built with Flutter for Windows desktop. This project is part of my journey to learn Flutter and improve my programming skills by building real applications

## 👨🏼‍💻​Information

I get the weather data from the [Open-Meteo API](https://open-meteo.com/). In my app, the weather information is currently fixed to Annaba, Algeria. It's just a beginner project for now.

## 🚀Getting Started

1. Clone the repository:

- ```git clone https://github.com/Talha0Abid/Simple-Weather-App.git```

2. Open the project directory:

- ```cd weather_app```

3. Install the dependencies:

- ```flutter pub get```

4. Run the application on Windows:

- ```flutter run -d windows```
